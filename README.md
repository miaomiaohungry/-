# 通勤账本

可独立部署的手机网页，用通勤日历比较上海地铁计次票与普通支付的完整费用。

## 使用

安装 Node.js 后，在此目录运行 `node server.mjs`，打开 `http://127.0.0.1:4173`。无需安装依赖。部署静态网站时上传 `dist` 中全部文件即可。

输入地铁与公交单程价格，分别选择去程、回程的换乘方向，选择年份月份并点选通勤日。页面自动显示四档次卡与普通支付的费用、最低方案及逐程支付安排。设置和各月日期保存在当前浏览器中。

## 计算范围

- 比较不买卡及分别购买一张 35、45、60、90 次卡的方案。采用动态规划寻找每一方案中次卡与普通支付的最低费用组合。
- 以分为单位逐程计算。只有普通支付的地铁实付计入每自然月满 90 元门槛，跨过门槛后的下一程开始享九折。
- 次卡消费不参加满额和换乘优惠，公交另付。次卡未覆盖或过期后的行程普通支付。
- 默认有效期含激活日 31 天，可改为 30 天，激活日期留空时采用所选首日。
- 公交转地铁默认先打折再减换乘优惠，也提供另一叠加顺序。来源页面未明确这项细节，应根据实际支付渠道核对。
- 本月预算包含一张次卡的全额购买成本。剩余次数显示在结果中，跨月余次价值不抵扣本月费用。界面可输入选中首程之前的当月已累计地铁金额，该金额只影响门槛。
- 自动日历含已公布的 2026、2027 年假日和补班。其他年份默认周一至周五并显示提醒。

## 数据来源

规则核对于 2026 年 11 月 24 日，适用 2026 年 12 月新政策。当前使用已核对快照，不自动抓取更新。

- [票价与次卡查询](https://metroplatform.tenchii.com/web/fare-query/h5/index)
- [上海市交通委票价批复](https://jtw.sh.gov.cn/zxzfxx/20261120/cf0d77dcb4414d5dbdc13b0edb455bba.html)
- [2026 年假日安排](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)
- [2027 年假日安排](https://chinajob.mohrss.gov.cn/h5/c/2026-11-09/635850.shtml)
- [功能参考](https://onionmili.github.io/shmetro-calc/)

界面与实现独立编写。计费参数、次卡、节假日在 `dist/rules.js`，算法在 `dist/engine.js`。

## 验证

运行 `node --test tests/engine.test.mjs`。覆盖 18/19 趟分界、90 元门槛、公交方向和折扣顺序、次卡用完及到期、零出行、节假日，以及对支付方式穷举结果的独立核对。
